# **Drive Mechanism Evaluation Tool**

Python-based reservoir engineering project to analyse the impact of multiple drive mechanisms on hydrocarbon recovery.

## Overview
This project evaluates a conceptual petroleum reservoir under each drive mechanism:

- Rock and fluid expansion.
- Solution gas drive.
- Gas cap drive.
- Gravity drainage.
- Weak aquifer drive.
- Strong aquifer drive.

The model calculates:

- Gross Rock Volume (GRV).
- Stock Tank Original Oil In Place (STOOIP).
- Productivity Index.
- Flow rate over time.

## Results
The analysis demonstrates that how recovery efficiency varies depending on the reservoir energy mechanism.
